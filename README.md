# LA BOGOTÁ SATÍRICA DE SIN REMEDIO · V08

Un visualizador interactivo de investigación y creación para la Maestría en Humanidades Digitales de la Universidad de los Andes.

## Iniciar en macOS

Requiere Node.js 20 o posterior.

```bash
npm ci
npm run dev
```

Abrir la dirección local que anuncie Vite, normalmente http://localhost:5173.

## Interacción

- Mover el globo: arrastrar con el ratón o el dedo.
- Entrar al recorrido: W o doble clic/doble toque.
- W / ↑: avanzar sobre una vía; S / ↓: retroceder.
- A / D (← / →): escoger salida en una bifurcación, no atravesar el terreno libremente.
- Interior: ↑ muestra el siguiente momento narrativo, ↓ vuelve al anterior. ESC regresa al exterior. Las elecciones aparecen después del episodio y pueden pulsarse o seleccionarse con 1–3.
- N avanza el ciclo día/noche para pruebas. Luna: información de la investigación. Centrar: volver a vista general.

## Alcance

La ciudad es una cartografía especulativa, **no una restitución catastral exacta de Bogotá**. Hay doce lugares visuales, de los cuales once son episodios accesibles. Los Cerros son un paisaje integrado al suelo y no se caminan.

Los pasajes de novela se distinguen de las acotaciones editoriales y las bifurcaciones satíricas originales. Esta versión requiere una validación estética, literaria y de jugabilidad en la máquina final de la investigadora.

Para la documentación y los límites de esta entrega, consulta `docs/V08_DECISIONES_Y_VALIDACION.md`.
